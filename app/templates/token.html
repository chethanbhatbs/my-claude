Where these numbers come from (and what leaves this machine)
One request: GET https://api.anthropic.com/api/oauth/usage, authorised with your Claude Code OAuth token read from the macOS keychain entry Claude Code-credentials — the same entry the claude CLI made and uses. The token is sent in the Authorization header and nothing else goes with it: no transcripts, no prompts, no filenames, no telemetry. It is held in memory for 10 minutes and never written to disk. This happens only while this page is open (on load, every 60s, and on Refresh). Decline the keychain prompt and nothing breaks — the panel falls back to the copy Claude Code already cached in ~/.claude.json and says so, with the age of those numbers. Every other page in this app is computed from files on your disk with no network access.

  • Cache reads are billable (~10% price) but not shown as "new" tokens in Claude Desktop's headline. "Cache saved" is the difference vs paying full input price.
